# Player Statistics Analyzer

## Project Description

Player Statistics Analyzer is a Python application for storing and analyzing player match statistics.

The program allows users to:
- load player data from JSON files
- calculate average scores
- generate leaderboards
- find the best player performance
- save reports into output files

The project demonstrates:
- Object-Oriented Programming
- file handling with JSON
- algorithms and collections
- decorators and generators
- unit testing

## How to Run the Project

1. Open the project folder.

2. Run the program:

```bash
python main.py
```

3. Run tests:

```bash
python -m unittest
```
